# TK Random

Десктопное приложение (Windows) для автоматической жеребьёвки соревнований по тхэквондо. Хранит список участников, само определяет возрастную и весовую категорию каждого и случайным образом формирует турнирную сетку (кто с кем встречается) внутри каждой категории.

## Возможности

- **Участники** — добавление, редактирование и удаление спортсменов: Ф.И., год рождения, пол, вес, клуб/тренер. Категория и весовая категория считаются автоматически (по текущему списку категорий) и видны прямо в форме.
- **Категории** — отдельный экран, где можно добавлять, редактировать, переставлять по порядку и удалять возрастные категории; для каждой задаются границы года рождения и весовые категории (кг) отдельно для мужчин и женщин. Приложение поставляется с 4 предустановленными категориями (см. ниже), но их можно менять полностью.
- **Жеребьёвка** — участники автоматически группируются по категории, полу и весу; по каждой группе одной кнопкой формируется случайная сетка на выбывание (с корректной расстановкой "байев", если число участников не кратно степени двойки).
- **Печать / экспорт** — готовая сетка выгружается в PDF и отправляется на печать (в том числе «Печать в PDF» средствами Windows).
- **История** — сформированные сетки сохраняются по турнирам и всегда доступны для повторного просмотра и печати; название и весовые границы категории сохраняются вместе со сформированной сеткой, поэтому история остаётся читаемой, даже если категорию потом переименуют или удалят.
- **Проверка обновлений** — при запуске приложение тихо сверяется с последним релизом на GitHub; если вышла более новая версия, предлагает открыть страницу релиза для скачивания (сама ничего не подменяет, данные не трогает).
- Все данные хранятся локально на устройстве и не пропадают после перезапуска программы.

## Возрастные категории (по умолчанию)

Категории полностью редактируемые (экран «Категории»); ниже — значения, с которыми приложение запускается впервые.

| Категория | Год рождения |
|---|---|
| Взрослый | 2009 и старше |
| Юниор | 2010–2012 |
| Кадет | 2013–2015 |
| Дети челленджер | 2016–2017 |

## Весовые категории (кг, по умолчанию)

Спортсмен попадает в ближайшую категорию, вес которой **не меньше** его собственного (по правилу "до X кг"); свыше последней границы — открытая категория `+X`. Эти границы задаются отдельно для каждой возрастной категории на экране «Категории».

| Категория | Мужчины | Женщины |
|---|---|---|
| Взрослый | 54, 58, 63, 68, 74, 80, 87, +87 | 46, 49, 53, 57, 62, 67, 73, +73 |
| Юниор | 45, 48, 51, 55, 59, 63, 68, 73, 78, +78 | 42, 44, 46, 49, 52, 55, 59, 63, 68, +68 |
| Кадет | 33, 37, 41, 45, 49, 53, 57, 61, 65, +65 | 29, 33, 37, 41, 44, 47, 51, 55, 59, +59 |
| Дети челленджер | 26, 28, 30, 32, 34, 36, 38, 40, 42, +42 (общий список для м/ж) | |



Собранное приложение появится в `build/windows/x64/runner/Release`.

## Выпуск новой версии (для обновления у пользователей)

Обычный `git push` в `main` только собирает и тестирует (CI-проверка), релиз не публикует — иначе каждый коммит слал бы всем "есть обновление". Чтобы приложение у уже установивших его пользователей увидело новую версию:

1. Поднять номер версии в `pubspec.yaml` (`version: X.Y.Z+N`).
2. Закоммитить.
3. Поставить тег `vX.Y.Z` (должен совпадать с версией в `pubspec.yaml`) и запушить его:
   ```bash
   git tag v1.2.0
   git push origin v1.2.0
   ```
4. GitHub Actions соберёт релизную сборку и опубликует её как [Release](https://github.com/Bnutss/TK-Random/releases) с прикреплённым `tk_random-windows.zip`.

При следующем запуске уже установленное приложение это увидит и предложит скачать — распаковать zip нужно поверх текущей папки установки, локальные данные (участники/категории/история) при этом не трогаются.

## Тесты

```bash

```

Покрывают определение возрастной/весовой категории и алгоритм формирования сетки (равномерное распределение байев, отсутствие пар "байй против байя", корректный проход участников в следующий круг).

```
lib/
  models/     — Athlete, редактируемые возрастные/весовые категории, модели турнирной сетки
  services/   — хранилище участников/категорий/турниров, генератор сетки, экспорт в PDF, проверка обновлений
```
